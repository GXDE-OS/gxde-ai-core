Fake OAI endpoints

Introduction

This is a fake OAI-compatible end point that allow you to test your AI locally.

Documentation

You may generate the documentation by running following command:

$ ./gradlew clean javadoc

The document may be found at build/docs/javadoc/index.html.

Code Style Guide

You need to follow Google Java Style Guide.

Auto Code Style Checks

Gradle uses Checkstyle 14.3.0's google_checks.xml to check production & testing code. Note that any warning or error will make the check fail. If you trigger check or build, the code style check will be also triggered.

Check Style Manually

You may simply run the code style checking + unit tests manually by running:

$ ./gradlew clean check

If you only need to check code style:

$ ./gradlew checkstyleMain checkstyleTest

Your report will be available in build/reports/checkstyle/.

Please note that while Checkstyle checks your code style, it does not re-format your code automatically.
